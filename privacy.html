Privacy Policy

Last updated: 24 September 2026

StokVideoYap is a private tool used only by its owner to upload his own video files to his own Google Drive.

Data accessed

The app uses the Google Drive scope drive.file. It can only see and manage files and folders that it created itself. It cannot read any other file in the Drive.

Data use and sharing

No data is collected, stored on any server, sold or shared with third parties. Access tokens stay only on the owner's own computer.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
